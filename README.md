Project Contents

The project folder contains:

* src: Java source code.
* bin: Compiled Java files.
* Word document: Project report and screenshots.
* .project and .classpath: Eclipse configuration files.

How to Run the Application

1. Open Eclipse IDE.
2. Click File - Import.
3. Select General - Existing Projects into Workspace.
4. Click Next.
5. Browse and select the project folder.
6. Click Finish.
7. Open the src folder.
8. Open Main.java.
9. Right-click and select Run As -Java Application.
10. View the output in the Console.

How to Open the Report

1. Open the project folder.
2. Locate INVENTORY SYSTEM MANAGEMENT REPORT.
3. Double-click to open it in Microsoft Word.
4. View the report and application screenshots.
